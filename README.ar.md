# SupplyFlow | مراقبة سلسلة التوريد

[العربية](README.ar.md) | [English](README.md)

**SupplyFlow** هي واجهة أمامية ثنائية اللغة (العربية والإنجليزية) لفكرة منصة
لإدارة سلسلة التوريد. تهدف إلى جمع التجار والموردين/المصنّعين وشركات الخدمات
اللوجستية والعملاء ضمن تجربة مترابطة للتجارة والتوصيل.

### ما يتضمنه المشروع

- صفحة تعريفية تدعم التبديل بين العربية والإنجليزية، مع اتجاه عرض مناسب لكل لغة
  (من اليمين إلى اليسار أو من اليسار إلى اليمين).
- قسم يعرّف بخدمات المنصة للتجار والمصنّعين ومزودي الخدمات اللوجستية والعملاء.
- صفحات لتسجيل الدخول وإنشاء الحساب.
- نموذج تسجيل يرسل الاسم والبريد الإلكتروني وكلمة المرور ونوع الحساب إلى واجهة
  التسجيل في الخادم الخلفي.

المستودع الحالي يحتوي على الواجهة الأمامية فقط. صفحة تسجيل الدخول واجهة شكلية
وليست مرتبطة حاليًا بخدمة مصادقة. كما أن تتبع الشحنات المباشر وإدارة الطلبات
ولوحات متابعة العمليات غير منفذة في هذا المشروع.

### التقنيات

- Next.js 16 باستخدام App Router وReact 19
- TypeScript
- Tailwind CSS 4
- Axios لإرسال طلبات التسجيل إلى الواجهة الخلفية

### المتطلبات

- Node.js وnpm
- خدمة خلفية تنفذ `POST /api/auth/register` لاستخدام ميزة إنشاء الحساب

### التشغيل محليًا

1. ثبّت الاعتماديات:

   ```bash
   npm install
   ```

2. لتفعيل التسجيل، أنشئ ملف `.env.local` في المجلد الرئيسي للمشروع وحدد عنوان
   الخدمة الخلفية:

   ```env
   NEXT_PUBLIC_API_BASE_URL=http://localhost:8080
   ```

   استخدم العنوان المناسب لبيئة الخادم لديك. تضيف صفحة التسجيل المسار
   `/api/auth/register` إلى هذا العنوان. يجب أن تستقبل الخدمة الخلفية الحقول
   `name` و`email` و`password` وأحد أنواع الحسابات التالية: `CUSTOMER` أو
   `MERCHANT` أو `MANUFACTURER` أو `LOGISTICS_PROVIDER`.

3. شغّل خادم التطوير:

   ```bash
   npm run dev
   ```

4. افتح [http://localhost:3000](http://localhost:3000).

### الأوامر المتاحة

| الأمر | الوصف |

| المسار | الوصف |
