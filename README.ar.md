# SupplyFlow | مراقبة سلسلة التوريد

[العربية](README.ar.md) | [English](README.md)

**SupplyFlow** واجهة أمامية ثنائية اللغة (العربية والإنجليزية) لمنصة تجارة
وسلسلة توريد مترابطة، تجمع التجار والموردين والمصنّعين ومزودي الخدمات
اللوجستية والعملاء.

## المميزات

- صفحة تعريفية باللغتين مع تبديل اللغة وتغيير اتجاه العرض بين RTL وLTR.
- نموذجا تسجيل الدخول وإنشاء الحساب، مع رسائل توضيحية وحالات تحميل. يدعم
  التسجيل أنواع الحسابات: العملاء والتجار والمصنّعون ومزودو الخدمات اللوجستية.
- ملف شخصي على المسار `/profile/[id]` يعرض بيانات المستخدم المسجل دخوله،
  ويتيح تغيير نوع الحساب وتسجيل الخروج.
- مظهر داكن وفاتح يتبع إعداد النظام حتى يختار المستخدم مظهرًا، مع حفظ الاختيار
  في تخزين المتصفح.
- صفحة مخصصة للمسارات غير الموجودة ومكونات واجهة ونماذج تراعي سهولة الوصول.
- توثيق استخدام المكونات وإرشادات سهولة الوصول في
  [app/UI_COMPONENTS.md](app/UI_COMPONENTS.md).

يحتوي هذا المستودع على الواجهة الأمامية فقط، ويلزم وجود خادم خلفي متوافق
للمصادقة وإنشاء الحساب. محتوى الشحن المعروض في الصفحة التعريفية توضيحي؛ أما
التتبع المباشر للشحنات وإدارة الطلبات ولوحات متابعة العمليات فغير منفذة.

## التقنيات

- Next.js 16 باستخدام App Router وReact 19
- TypeScript
- Tailwind CSS 4
- Axios للاتصال بالخادم الخلفي
- الخطان IBM Plex Sans Arabic وIBM Plex Mono

## المتطلبات

- Node.js وnpm
- خادم خلفي يوفّر واجهات المصادقة أدناه لاستخدام التسجيل وتسجيل الدخول وتغيير
  نوع الحساب

## التشغيل محليًا

1. ثبّت الاعتماديات:

   ```bash
   npm install
   ```

2. أنشئ ملف `.env.local` في المجلد الرئيسي للمشروع وحدد عنوان الخادم الخلفي:

   ```env
   NEXT_PUBLIC_API_BASE_URL=http://localhost:8080
   ```

   تضيف الواجهة هذه المسارات إلى العنوان الأساسي:

   | الطريقة | المسار | الغرض |
   | --- | --- | --- |
   | `POST` | `/api/auth/register` | إنشاء حساب بالحقول `name` و`email` و`password` و`role` |
   | `POST` | `/api/auth/login` | تسجيل الدخول بالحقول `email` و`password` وإرجاع رمز مصادقة وبيانات المستخدم |
   | `PATCH` | `/api/auth/updaterole` | تحديث `role`؛ يتطلب الترويسة `Authorization: Bearer <token>` |

   أنواع الحسابات المدعومة هي `CUSTOMER` و`MERCHANT` و`MANUFACTURER` و
   `LOGISTICS_PROVIDER`. يجب أن تتضمن استجابة تسجيل الدخول `token` أو
   `accessToken`، ويمكن أن تتضمن بيانات المستخدم في الحقل `user`. تحفظ الواجهة
   الرمز وبيانات المستخدم في `localStorage` بالمتصفح لاستخدام جلسة الملف الشخصي.

3. شغّل خادم التطوير على المنفذ 3001:

   ```bash
   npm run dev -- --port 3001
   ```

4. افتح [http://localhost:3001](http://localhost:3001).

## الأوامر المتاحة

| الأمر | الوصف |
| --- | --- |
| `npm run dev` | تشغيل خادم التطوير (المنفذ الافتراضي في Next.js هو 3000) |
| `npm run build` | إنشاء نسخة الإنتاج |
| `npm run start` | تشغيل خادم الإنتاج |
| `npm run lint` | تشغيل ESLint |

## المسارات الرئيسية

| المسار | الوصف |
| --- | --- |
| `/` | الصفحة التعريفية باللغتين |
| `/login` | نموذج تسجيل دخول متصل بالخادم الخلفي |
| `/register` | نموذج إنشاء حساب متصل بالخادم الخلفي |
| `/profile/[id]` | الملف الشخصي للمستخدم المسجل وتعديل نوع الحساب |
| المسارات الأخرى | صفحة مخصصة لخطأ 404 |
